# Booktracker

**Booktracker** is a website with which users can track what books they have read and what books they
might want to read in the future. Booktracker has a dataset with some data about the reading habits of
its users. The data contains information about the users and how many pages they have read of certain
books.

This console-based application is built with Java and allows the user to gain access and modify the dataset.

## Features
1. Add a user to the database
2. See all the reading habit data for a user
3. Change the title of a book
4. Delete a reading habit
5. Provide the mean age of the users
6. Provide the total number of users that have read pages from a specific book
7. Provide the total number of pages read by all users
8. Provide the total number of users that have read more than one book

## How to run

The application is built with Java and can be run using a Java editor, for example, IntelliJ IDEA.
When opening the project, the application can be started by pressing `CTRL + F5`

There is also a precompiled build of the application in the out/artifacts/BookTrack_jar directory.
To run this build, open a terminal and navigate to the directory. You can then run the jar by typing `java -jar BookTrack.jar`.

## How to use

Upon starting the application, the user will be presented with a menu. The menu shows the different operations that the user can perform within the system. 
The user navigates through the prompts by entering numbers corresponding to the options.

To exit the application, press `0` when prompted.
